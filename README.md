# Cleam Digital

Portfólio da Cleam Digital: social media, audiovisual e design gráfico.

O site é um único arquivo, `index.html`.

- **Social media:** projetos do Behance (lista `PROJETOS` no `index.html`).
- **Audiovisual:** vídeos do Behance (lista `VIDEOS`).
- **Feedbacks:** salvos no Supabase (projeto `cleam-digital`). Aparecem no site depois de marcar `aprovado` na tabela `feedbacks`.
- **Orçamento:** monta a mensagem e abre o WhatsApp.
